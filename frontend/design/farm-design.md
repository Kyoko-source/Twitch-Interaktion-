# Quatschfarm

Image Gen primary concept: exec-6d0ea5ee-05d0-483a-a3d8-e1c15f7e63a4.png, 1536×1024, generated before implementation.

Visual system: deep forest #142821, surfaces #102b23, cream #fff2d9, butter yellow #f4c76c, sage #a9d3aa, border #36594c. Georgia display titles, Segoe UI body/chrome. 44px touch controls, 12–16px body, 28–46px titles, 14px panels. Main hierarchy: header/counters/control, generated illustrated pasture left, soundstudio right, integrated progress footer, six species shop rail and actual herd list below. No rasterized text/controls. The generated meadow is unwashed; animals use a transparent four-column, three-row idle/calling atlas. Foreground details remain in the background asset, gameplay animals are independently animated.

Native workflow: select animal → record max four seconds → preview/name → save privately to account → start farm → scheduled calls mint separate farm coins → buy animals → assign individual/shared recorded voices → expand to 100. Each species pays more per call. Per-species prices grow 16% after each paid purchase. No Chicken conversion or offline income. Pause/mute, volume and sound density are distinct controls. Account storage, empty library, mic permissions, upload fallback, saving and retry states extend the concept's native component family. A voice is required before the first paid animal call; new animals inherit the selected voice and can be edited individually. Demo names/values become actual account data. Mobile stacks pasture/studio and shows the six-species shop in a horizontal rail.
